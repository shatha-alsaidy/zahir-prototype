# ZAHIR

## 📌 Overview

ZAHIR is an intelligent AI system designed to detect hidden or encoded expressions used in online content that may indicate the promotion of prohibited materials. It aims to support security and monitoring entities by analyzing textual data and uncovering disguised or indirect language patterns.

The system is built on advanced NLP techniques and Arabic language modeling to identify subtle or encrypted expressions that are difficult to detect using traditional methods.

---

## ⚠️ Problem Statement

With the rapid growth of social media platforms, prohibited content is often promoted using:
- encrypted language
- indirect expressions
- slang and coded terms

These methods make it difficult for traditional monitoring systems to detect harmful content in time, leading to delays in intervention and inefficient use of resources.

**Target Users:**  
Security and regulatory authorities responsible for monitoring digital platforms.

---

## 💡 Proposed Solution

ZAHIR is an AI-powered detection system that analyzes text content and identifies hidden or encoded expressions that may indicate suspicious or prohibited activity.

It uses:
- Advanced **NLP** models for Arabic and dialect understanding  
- **Semantic analysis** to detect implicit meanings  
- Synthetic data generation to simulate real-world encoded language patterns  

The system transforms raw text into structured insights for faster and more accurate decision-making.

---

## 🧠 Key Features

- Detection of encoded or hidden expressions in text  
- Support for Arabic dialects and linguistic variations  
- Semantic similarity analysis using transformer models  
- Zero-shot classification for flexible detection categories  
- Synthetic data generation for training robustness  
- Lightweight and scalable AI pipeline  

---

## 🧰 Built With

**Python**: Core development environment and file handling  
**Streamlit**: Interactive user interface for text analysis and visualization  
**Farasa**: Arabic text processing (tokenization, segmentation, POS tagging) 
**PyTorch**: Deep learning framework for model execution  
**Sentence-Transformers (intfloat/multilingual-e5-large)**: Semantic embedding generation for text understanding  
**Hugging Face Transformers (xlm-roberta-large-xnli)**: Zero-shot text classification  
**Sentence-Transformers Utilities (cosine similarity)**: Semantic similarity scoring between text embeddings  
**Hugging Face Datasets (mOSCAR)**: Large-scale multilingual Arabic corpora for training and evaluation (streaming mode, multiple dialect configs)  

---

## 📊 Impact & Benefits

- Improves early detection of suspicious or encoded communication  
- Reduces manual monitoring workload for security teams  
- Enhances accuracy of digital surveillance systems  
- Speeds up identification of potential threats  
- Provides scalable and cost-efficient monitoring using open-source AI  

---

## 🎯 Goal

To enhance digital safety by enabling intelligent detection of hidden or encoded language patterns in online content using advanced Arabic NLP and AI techniques.
